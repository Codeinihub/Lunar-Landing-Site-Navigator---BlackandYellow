## Summary
Earth Detective is a web-based environmental data exploration platform designed to help users investigate changes in Earth's environment using NASA data. I developed an interactive website featuring a world map where users can select specific locations or geographical regions, choose date ranges, and explore environmental data. The platform is being designed to let users select different data categories, such as precipitation and temperature, and specific measurements, such as rain depth, through dynamically generated dropdown menus connected to a FastAPI backend. 

The project addresses the challenge of making complex environmental datasets easier to access, navigate, and understand. By combining interactive mapping with customizable data requests, users can investigate environmental trends in areas that interest them. This is important because understanding changes in Earth's climate and environment helps people recognize patterns, investigate potential environmental issues, and make more informed decisions.

## Project Details
Project Details –  Earth Detective 

Earth Detective is a team-developed environmental data exploration website designed to make NASA's Earth observation data easier to access and investigate. Our platform allows users to select geographical locations by entering a place or interacting with an interactive world map. Users can click to select an exact point or drag to outline a larger geographical region. They can also choose a start and end date to investigate environmental changes over a specific period. 

Our platform is being developed to connect with NASA data through a Python FastAPI backend. Users will be able to choose environmental data categories, such as precipitation or temperature, and select specific measurements, such as rain depth. These options will be retrieved dynamically from the backend. 

Benefits and Intended Impact: 

Our main goal is to make complex scientific data more accessible and easier to explore. Instead of navigating complicated datasets, users can customize their searches based on location, time, and environmental measurements. We hope our project encourages curiosity about Earth's changing environment, supports environmental research, and helps people recognize patterns connected to climate change and other environmental challenges. 

Tools and Technologies: 

HTML – structures the website and its content. 

CSS – creates the visual design and responsive layout. 

JavaScript – powers interactive features and backend requests. 

Python – handles backend programming. 

FastAPI – connects the website to environmental datasets. 

Leaflet.js – creates the interactive world map. 

NASA data services – provide the environmental data being explored. 

Visual Studio Code and GitHub – support development and collaboration. 

Creativity and Design Considerations: 

Our creative approach combines an interactive geographical map with customizable scientific data requests. Rather than restricting users to predetermined locations, we allow them to investigate areas that interest them. As a team, we consider accessibility, ease of navigation, geographical accuracy, data availability, website performance, and future expansion.
